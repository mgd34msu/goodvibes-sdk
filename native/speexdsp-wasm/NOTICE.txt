goodvibes-speexdsp-preprocess (WebAssembly build of SpeexDSP's preprocessor)
============================================================================

This WebAssembly module is a build of the noise-suppression (preprocessor)
portion of SpeexDSP 1.2.1, plus a small entry-point file written for this
project. It is what `voice.wake.noiseSuppression: "speex"` runs, on every
surface that runs it.

Redistributing the module — as a file, or embedded in a JavaScript bundle as
the SDK does — carries the BSD 3-clause conditions below, which REQUIRE that
this copyright notice, the condition list and the disclaimer be reproduced with
it. That is why this notice is carried in the repository beside the artifact
rather than left in the upstream tarball.


Upstream component
------------------

  SpeexDSP 1.2.1
  https://gitlab.xiph.org/xiph/speexdsp
  Source archive: https://github.com/xiph/speexdsp/archive/refs/tags/SpeexDSP-1.2.1.tar.gz
  Archive sha256: d17ca363654556a4ff1d02cc13d9eb1fc5a8642c90b40bd54ce266c3807b91a7
  License: BSD 3-clause (see SpeexDSP-1.2.1-COPYING.txt, reproduced verbatim)

  Files compiled into the module:
    libspeexdsp/preprocess.c   the noise suppressor itself
    libspeexdsp/filterbank.c   the mel/Bark filterbank it estimates noise over
    libspeexdsp/fftwrap.c      the FFT wrapper, built with USE_SMALLFT
    libspeexdsp/smallft.c      the real FFT (FFTPACK derivative carried by SpeexDSP)

  No other SpeexDSP component is present: there is no echo canceller, no
  resampler, no jitter buffer, and no Speex codec.

Written for this project
------------------------

  native/speexdsp-wasm/gv-speex-preprocess.c   the WebAssembly entry points
  native/speexdsp-wasm/os_support_custom.h     SpeexDSP's OS hooks, minus stdio
  native/speexdsp-wasm/speexdsp_config_types.h the fixed-width typedefs its
                                               configure script would generate

These carry the SDK's own MIT license.


C runtime linked into the module
--------------------------------

  wasi-libc (https://github.com/WebAssembly/wasi-libc), used for `calloc`/`free`
  and the libm functions SpeexDSP calls (exp, log, pow, sin, cos, atan, sqrt,
  floor). wasi-libc is triple-licensed Apache-2.0 WITH LLVM-exception,
  Apache-2.0, or MIT.

  The built module imports nothing at all: no WASI syscalls, no JavaScript glue.
  Its only import-side requirement is a host that can instantiate WebAssembly.
